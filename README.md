# Negradlc1 / Negradlc 0.4.0

Клиентский мод для **Minecraft Java 1.21.4 · Fabric · Java 21**.

## Скачать и установить

Готовая сборка: [`dist/negradlc-0.4.0.jar`](dist/negradlc-0.4.0.jar). На странице файла нажмите **Download raw file**. Контрольная сумма находится рядом в `dist/SHA256SUMS`.

Установите Fabric Loader **0.16.10+** и Fabric API **для 1.21.4**, положите JAR в `mods` и удалите старую версию Negradlc из этой папки. Перезапустите игру. `sources.jar` устанавливать не нужно.

## Меню и бинды

**Right Shift** открывает меню. Клавишу открытия можно поменять в обычных настройках управления Minecraft.

- **ЛКМ по заголовку модуля:** включить/выключить.
- **ПКМ по заголовку:** раскрыть его настройки.
- **Средняя кнопка по заголовку:** назначить бинд. Затем нажмите клавишу, кнопку мыши или прокрутите колесо вверх/вниз.
- **Esc** отменяет ввод бинда; **Delete/Backspace** снимает назначение.
- Уже занятая клавиша переносится с предыдущего модуля. Right Shift зарезервирован для меню.
- Бинд на колесо действует только в игре и поглощает прокрутку в назначенном направлении, чтобы одновременно не менялся слот хотбара. В меню колесо прокручивает настройки; во время назначения оно записывает бинд.
- **Ctrl+F** переводит фокус в поиск по текущей вкладке (включая названия настроек). Esc очищает поиск, повторный Esc закрывает меню. Открытые карточки и выбранная вкладка запоминаются до выхода из игры.
- **ЛКМ по + / −** раскрывает настройки без включения модуля.
- Перетащите верхнюю полосу для перемещения окна, правый нижний угол — для изменения размера.

Тёмные полупрозрачные панели, бирюзовые акценты, луна и две колонки раскрывающихся модулей сделаны по предоставленному образцу. При узком окне остаётся одна колонка. Меню не использует внешние библиотеки UI.

## Combat: если не бьёт

**Crit only выключен по умолчанию в новых настройках.** При выключенном Crit only KillAura и TriggerBot могут бить с земли. Существующая настройка из старого JSON сохраняется: если у вас уже был включён Crit only, он останется включённым.

При включённом **Crit only** удар возможен только при настоящем падении без спринта. **Auto crit jump** делает обычный прыжок, когда цель в прицеле и атака заряжена. Combat останавливает спринт, AutoSprint освобождает его на время этого режима. Для Minecraft 1.21.4 падение отслеживается по реальному снижению позиции: клиентское поле fallDistance само по себе могло оставаться нулевым. Если автопрыжок выключен, прыгайте самостоятельно.

**AirStag, полёт, лестница, вода, транспорт и слепота мешают критам.** Невозможные условия не подменяются обычным ударом: причина ожидания показывается в Target HUD, в том числе когда цель не найдена. Чтобы бить без прыжков, выключите Crit only.

**Цели:** по умолчанию только игроки. Для одиночного мира включите Hostile mobs или Passive mobs в карточке **Targets**. Творческие игроки, наблюдатели и друзья исключаются. Друзья редактируются через **Manage friends**. Удары через блоки не выполняются.

- **KillAura:** **Snap** быстро захватывает цель ограниченным по скорости поворотом, **Snap Legit** поворачивается мягче, **Smooth** плавно сопровождает цель. Даже Snap не телепортирует камеру на 180 градусов. Камера держит одну цель между ударами: обратный рывок после каждого удара убран.
- **Return view** делает один плавный возврат при потере цели или выключении KillAura. Движение мышью отменяет возврат; новая цель отменяет незавершённый возврат. У KillAura свои точка наведения, скорости, плавность, ускорение, deadzone, удержание и приоритет целей.
- **Aim Assist:** работает и при включённой KillAura, когда цель находится за её melee-дальностью. Один контроллер управляет камерой в каждый момент: KillAura имеет приоритет только при своей доступной цели. В HUD показаны причины ожидания: Hold attack, выключенные фильтры мобов, дальность/FOV.
- Для постоянного аима выключите **Hold attack** в Aim Assist. При включённом Hold attack нужно удерживать кнопку атаки. По умолчанию combat выбирает только игроков: для проверки на мобах включите их в **Targets**.
- **TriggerBot:** удар только по реальной цели под прицелом, с проверкой препятствий, cooldown и Crit only. **Crosshair dwell** задаёт время стабильного удержания одной цели (0–10 тиков; 1 тик = 0,05 с). Потеря/смена цели сразу сбрасывает ожидание; 0 сохраняет прежнее поведение.
- **Smooth aim** у TriggerBot по-прежнему опционален и выключен по умолчанию; использует настройки Aim Assist и собственный Assist FOV. Удар не проходит, пока реальный прицел не наведён на цель.

Настройки **Crit only / Auto crit jump**, их значения и существующие бинды при обновлении сохраняются. Критический блок и FallTracker не изменены.

## Visual / Move / Other

- **Jump Circle:** расширяющийся затухающий круг в точке прыжка, с настройками цвета, радиуса и длительности. Появляется при реальном прыжке, а не при сходе с края или телепорте.
- **Target Effects:** **Cube** (объёмный каркас), **Square** (квадрат к камере), **Circle** (анимированные кольца), **Points** (вращающаяся система светящихся точек). Настраиваются цвет, размер и скорость. Источник — текущая combat-цель или сущность под прицелом при включённом Crosshair fallback. Проверка видимости — отдельный переключатель.
- **World Particles:** End Rod / Enchant / Cherry, плотность в частицах в секунду и радиус вокруг игрока. Число создаваемых частиц ограничено; используются обычные времена жизни Minecraft.
- **World Customizer:** визуальные время суток, Clear / Rain / Thunder и оттенок неба с интенсивностью. Серверные часы, погода и пакеты не перезаписываются. Выключение возвращает настоящее состояние мира; настройки времени/погоды/оттенка включаются отдельно.


- **ESP:** экранные рамки вокруг сущностей, имена, расстояние, здоровье, отдельные фильтры игроков/мобов, дальность, толщина и цвет. Through walls разрешает отображение за блоками; при выключении используется проверка видимости сущности.
- **Tracers:** линии от центра экрана к сущностям, свои фильтры, цвет, дальность, толщина и Through walls.
- **HUD:** watermark с FPS, список модулей, здоровье цели и статус combat. Avoid overlap отводит Target HUD в сторону, если он перекрывает список модулей. В **Edit HUD layout** виджеты перетаскиваются и масштабируются за угол.
- **Fullbright:** повышает освещение, не меняя сохранённое значение gamma.
- **AutoSprint**, **AirStrafe**, **AirStag**. AirStag удерживает высоту, Jump поднимает, Sneak опускает; исходная гравитация восстанавливается при выключении/открытии меню/выходе.
- **Sounds:** короткие оригинальные мягкие звуки включения/выключения и кликов; есть громкость и отключение. Обычные настройки громкости Minecraft продолжают действовать.

Все боевые и movement-модули изначально выключены. Настройки, друзья, бинды и HUD сохраняются в `config/negradlc.json` игрового каталога. Повреждённый JSON резервируется перед записью новых настроек.

Сервер определяет результат ударов и движения; работа на конкретном сервере и обход античита не гарантируются.

## Для разработки

Нужен JDK 21 с `javac`. Используйте существующий checkout: отдельный Git worktree не требуется.

```bash
./gradlew build
./gradlew runClient
```

Windows: `gradlew.bat build` и `gradlew.bat runClient`. `build` выполняет компиляцию Minecraft/Fabric-интеграции, тесты и remap JAR. Результат — `build/libs/negradlc-0.4.0.jar`.

Отдельные тесты конфигурации, биндов, углов, движения и проекции без загрузки Minecraft:

```bash
./gradlew -p verification test
```

GitHub Actions запускает полную сборку и сохраняет артефакт. Оригинальные OGG-звуки воспроизводимо генерируются `python scripts/generate_sounds.py` (нужен ffmpeg).

В этой облачной среде:

```bash
export JAVA_HOME=/workspace/toolchains/jdk-21
export GRADLE_USER_HOME=/workspace/toolchains/gradle-home
export PATH="$JAVA_HOME/bin:$PATH"
./gradlew -Dhttps.proxyHost=proxy -Dhttps.proxyPort=8080 -Dhttp.proxyHost=proxy -Dhttp.proxyPort=8080 build
```
