# Negradlc

Клиентский мод для **Minecraft Java 1.21.4 / Fabric / Java 21**.

## Функции

- **KillAura:** выбор ближайшей доступной цели, проверка видимости и препятствий, поворот камеры, дальность до 3 блоков и настройка восстановления атаки.
- **TriggerBot:** удар по цели под прицелом с теми же фильтрами и cooldown. Если включена KillAura, она управляет выбором цели.
- **Aim Assist:** плавный поворот, дальность, горизонтальный FOV, скорость и активация при удержании атаки. При включении вместе с KillAura ограничивает скорость её поворота.
- **Crit only:** ждёт условий настоящего критического удара при падении. Самостоятельно не прыгает. Sprint и AirStag могут препятствовать критам: отключите их, чтобы падать без спринта.
- **Фильтры:** игроки, враждебные и мирные мобы отдельно. Мобы выключены по умолчанию. Список друзей редактируется прямо в меню; друзья, творческие игроки и наблюдатели исключаются из целей.
- **Movement:** AutoSprint, AirStrafe и **AirStag** — зависание с подъёмом на Jump и спуском на Sneak. При выключении, открытии меню, потере фокуса и выходе восстанавливается исходная гравитация.
- **Visuals:** Fullbright, watermark, список включённых модулей, HUD цели с её здоровьем и расстоянием.
- **Click GUI:** вкладки Combat / Movement / Visuals / Settings, прокрутка, перетаскивание за заголовок и изменение размера за правый нижний угол.
- **HUD editor:** перемещение виджетов и масштабирование за угол. Положение и размер каждого виджета сохраняются.
- **Бинды:** назначаются каждому модулю в Settings. Нажмите строку и клавишу; Delete/Backspace снимает назначение, Esc отменяет ввод. Повторное назначение клавиши переносит её с прежнего модуля.

Все игровые модули изначально выключены. Мод отправляет обычные действия клиента; поддержка конкретного сервера и обход античита не гарантируются. Сервер может корректировать AirStag и другое движение.

## Установка и управление

1. Установите Minecraft **1.21.4**, **Fabric Loader 0.16.10+** и совместимый **Fabric API для 1.21.4**.
2. После успешной сборки скопируйте `build/libs/negradlc-0.1.0.jar` в папку `mods` вашего экземпляра игры. `-sources.jar` устанавливать не нужно.
3. Откройте меню клавишей **Right Shift**. Клавиша меню также доступна в обычных настройках управления Minecraft.
4. В Combat выберите цели и необходимые модули. Для ударов без ожидания падения выключите Crit only.
5. В Visuals нажмите **Edit HUD layout**, настройте виджеты и нажмите Esc для сохранения.

Настройки и бинды сохраняются в `config/negradlc.json` игрового каталога. Повреждённый JSON сохраняется в резервную копию перед записью новых настроек.

## Сборка и запуск из исходников

Нужен **JDK 21**, содержащий `javac`. Gradle Wrapper уже включён; SHA-256 дистрибутива проверяется автоматически.

```bash
./gradlew build
./gradlew runClient
```

Windows: `gradlew.bat build` и `gradlew.bat runClient`. Разрабатывайте в существующем checkout; отдельный Git worktree не требуется.

`build` компилирует мод, проверяет mixin через Loom, выполняет тесты и создаёт remapped JAR. Запуск `runClient` и функциональная проверка в мире необходимы дополнительно: успешная компиляция сама по себе не проверяет поведение в игре.

Для проверки конфигурации и расчётов независимо от Minecraft:

```bash
./gradlew -p verification test
```

Эта команда проверяет сохранение JSON/биндов/HUD, восстановление повреждённого файла, выбор углов, условия критов и расчёты движения. Она **не компилирует Minecraft-интеграцию**.

### Эта облачная среда

Подготовлены Java 21 и Gradle 8.12:

```bash
export JAVA_HOME=/workspace/toolchains/jdk-21
export GRADLE_USER_HOME=/workspace/toolchains/gradle-home
export PATH="$JAVA_HOME/bin:$PATH"
./gradlew -Dhttps.proxyHost=proxy -Dhttps.proxyPort=8080 -Dhttp.proxyHost=proxy -Dhttp.proxyPort=8080 build
```

Сохранённый сетевой черновик должен разрешать `maven.fabricmc.net`, `meta.fabricmc.net`, `libraries.minecraft.net`, `piston-meta.mojang.com`, `piston-data.mojang.com` и `resources.download.minecraft.net` в дополнение к стандартным доменам GitHub, Maven Central и Gradle. Для запуска потребуются игровые ресурсы Mojang.

На момент создания исходников полная сборка была заблокирована ответом **403 от прокси для maven.fabricmc.net**. Исходники Minecraft-интеграции и запуск клиента ещё не проверены. После применения сетевых настроек повторите полную сборку, затем проверьте в тестовом мире:

1. Открытие/закрытие меню, сохранение настроек после перезапуска, назначение и перенос биндов.
2. Перемещение и масштабирование HUD при разных размерах окна.
3. TriggerBot только под прицелом; исключение мобов/друзей; отсутствие ударов через блоки.
4. KillAura с crit only во время обычного падения, Aim Assist с удержанием атаки.
5. Включение/выключение AirStag, восстановление падения, изменение мира и респавн.
6. Fullbright в тёмном помещении и восстановление обычного освещения после выключения.

GitHub Actions настроен на полную сборку и сохранение JAR-артефакта; workflow выполнится после отправки репозитория в GitHub.
